# Overseer Releases

Public release channel for Overseer binaries and release metadata.

This repository contains:

- packaged desktop builds
- install and uninstall scripts
- checksums
- release manifests
- release notes mirrored from the main product repo

Current published structure:

- `dist/<tag>/...`
- `releases/releases.json`
- `releases/notes/<tag>.md`

The private source repo can reference this repository for public downloads without exposing application code.
